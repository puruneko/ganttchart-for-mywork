# Issue #0023: 「今日」に移動するボタンの追加

## ステータス

Open

## 概要

現在日時に視点を移動する `scrollToToday()` は `GanttChart.svelte` に既に実装されている（マウント時の自動スクロールや `pageshow` 復元時に内部で使用）が、ユーザーが任意のタイミングで手動実行できる UI ボタンが存在しない。ツールバーに「今日」ボタンを追加し、設定ボタン（`☰`）の隣に配置する。

## 仕様

- ツールバーに「今日」ボタンを追加し、クリックで `scrollToToday()` を実行する。
- 配置は設定パネル切り替えボタン（`.gantt-toggle-config-btn`、`☰`）の隣。
- 見た目は既存のツールバーボタン（ズームボタン等）と統一感のあるスタイルにする。

## 対象ファイル

| ファイル | 変更種別 |
